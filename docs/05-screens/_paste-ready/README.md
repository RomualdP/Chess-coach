## Workflow recommandé

### Sur mobile / app Claude

1. Ouvre le repo sur GitHub mobile.
2. Navigue dans `docs/05-screens/_paste-ready/`.
3. Tape le fichier que tu veux. Vue **Raw** (bouton en haut à droite).
4. Sélectionne tout, copie.
5. Colle dans Claude Design, ajoute "Génère les wireframes desktop + mobile" en bas.
6. Itère.

### Sur desktop

Ouvre le fichier en local, `cmd+A`, `cmd+C`, `cmd+V` dans Claude Design.
